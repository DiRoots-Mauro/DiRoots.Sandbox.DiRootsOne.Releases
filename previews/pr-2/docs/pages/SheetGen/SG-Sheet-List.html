    SheetGen

    Batch create Sheets and Placeholder sheets, place Views on Sheets based on a pre-defined template, and easily manage Drawing Sheets revisions. Export sheets/views lists to/from Excel.

    Sheet List

    The first step is to select the SheetGen from the DiRootsOne menu and choose the Sheet List tab. This page will show all sheets in the project.

    You must have at least one sheet created, to be used as a template in SheetGen.

    Sheet template

    The first step before you start managing the sheets in SheetGen, is to create a sheet as a template. Basically, you need to create a sheet and fill it in, organizing the views as you wish. So, that will be used to generate new sheets on SheetGen, which will have the same settings as the template sheet. A sheet template is simply a sheet with some views in place.

    Note: the version on the image may not reflect the latest version of SheetGen.

    New Sheet

    To create new sheets, you can use the New Sheet button, or you can right-click an existing sheet and choose Create Sheets from Template. You can create sheets from scratch and then edit their names, numbers, and parameters, or you can use existing placeholder sheets.

    From Sheet Template

    This tab allows you to create new sheets that will use a selected sheet as template, you can later change the sheets name, number and parameter values.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    1. Fill the options for the new sheets.
    • Number of Sheets - enter the number of sheets you want to create.
    • Populate View from template - create the new sheet with the same view settings as the template sheet.
    • Keep Legends - you can choose to keep the legends as the template sheet.
    • Keep Schedules - you can choose to keep the schedules as the template sheet.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    1. Select the existing sheet to be used as a template for the new sheet.

      You can use the search box to quickly find sheets contained in the project.

      Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    2. Note that the new sheets appear in the list of sheets, but have not yet been created in the project. To complete the creation, click Apply.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    From Placeholder Sheets

    This tab will allow you to convert placeholder sheets into actual sheets and lets you to select a sheet to use as template.

    Clicking Apply creates the sheets and deletes the original placeholder sheets from the project.

    You have the following options on each placeholder sheet:

    • Sheet to use as Template - select a sheet from the project to use as template (leave empty or select <None> to create an empty sheet).
    • Views (Populate Views from template) - duplicates the views from the template and places them in the same locations.
    • Legends - keep the legends from the template sheet.
    • Schedules - keep the schedules from the template sheet.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Actions between the sheets

    Open Sheet

    Right-click on the sheet and choose Open sheet option, to see the new sheet you have created.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Duplicate Sheet

    You can perform this action for individual sheets by right-clicking and choosing the Duplicate option, or you can perform this action in batch for several sheets simultaneously. To duplicate in batch, select the sheets you want, and in the Batch Actions list, choose Duplicate.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    1. Options for duplicating individual sheets.

      • Set a number of copies
      • Select the checkbox if you want to Duplicate Views from sheet
      • Select the checkbox if you want to Keep Legends from sheet
      • Select the checkbox if you want to Keep Schedules from sheet
      • Select the checkbox if you want to Copy Revisions from sheet
      • Select the checkbox if you want to Copy Title Block Parameter Values from sheet

      Note: If you prefer, you could select the checkbox Change Template for copies, so the list of sheets will be able to select another one.

      Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    2. Options for duplicating sheets in batch.

    • Set a number of copies
    • Select the checkbox if you want to Duplicate Views from sheet
    • Select the checkbox if you want to Keep Legends from sheet
    • Select the checkbox if you want to Keep Schedules from sheet
    • Select the checkbox if you want to Copy Revisions from sheet
    • Select the checkbox if you want to Copy Title Block Parameter Values from sheet

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Delete Sheet

    You can perform this action for individual sheets by right-clicking and choosing the Delete Sheet option, or you can perform this action in batch for several sheets simultaneously. To delete in batch, select the sheets you want, and in the Batch Actions list, choose Delete.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Add parameters columns

    By default, the list of sheets will only shows the the number and name of the sheet. Right-click under the column header and add the desired parameters.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Edit sheets Number and Name

    To edit the individual sheets, double-click on the cell you want to edit (number or name), and enter the text edit.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Import/Export excel file

    If you have several sheets created in the project, this tool makes editing much easier. Export an Excel file, edit it as you want, then import it into SheetGen and update the number and name of the sheets. Note that in the Sheet Name header column has a lock icon, by activating this icon, the column will be locked for any editing. In the Excel file exported you can numbering, naming, changing parameters and also add new rows to create new Sheets.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    1. Export the excel file from sheet list.

      Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    2. Once you have edited the Excel file, import it to SheetGen.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Rename

    SheetGen also allows sheets to be renamed in batch. To do this, select the sheets you want and click Rename. Then define a Prefix, a Suffix, enter the name that will be replaced and finally the name that will replace it.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Build Number and Build Name

    1. Similar the Rename tool, SheetGen has a Build Number. Select the sheets you want and click Build Number. Then set the Default Field Separator, Custom Field, Custom Separator, Counter and add or remove Parameters.

      Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    2. For the Build Name tool, it is the same steps. Select the sheets you want and click to Build Name. Then define the Default Field Separator, Custom Field, Custom Separator, and add or remove Parameters.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Save V/S Set

    To organize the project sheets, especially when there are many sheets created, SheetGen offers the tool to save sets. To create a new set, select the sheets you want to separate into this set and click on New Set, then assign a name to finish creating the set.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    You can also add sheets to an existing set.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Filter by V/S Sets

    Once you have organized the project sheets into sets, you can apply filters to make the work process easier.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    Clear editions

    1. Click the Clear all Modifications button, and reset all edition applied to the sheet names and numbers, in the table view by the Rename, Build Name or Build Number commands.

      Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.

    2. Click on the Clear Staging button, and clear the staging cached modifications.

    Note: With this tool, only changes that have not yet been applied will be cleared. Changes that have been applied cannot be cleared.

    Note: the version on the image may not reflect the latest version of SheetGen/DiRootsOne.
